# LiveLearn per un'altra docente (solo quiz)

Questo kit serve a installare una **copia personale** di LiveLearn: sito, database e password
della docente, separati da quelli di giacomocreations. Si usano solo i quiz.

## Per cominciare

Apri Claude sul tuo computer e scrivi:

> Leggi la guida https://raw.githubusercontent.com/giacomocreations/myclass/main/kit-livelearn/GUIDA-PER-CLAUDE.md
> e guidami passo passo a installare LiveLearn.

(Se hai ricevuto il kit come zip, allega anche la cartella o il file `GUIDA-PER-CLAUDE.md`.)

Ti servono: un account Google, circa 30-40 minuti, e la voglia di fare qualche clic su GitHub e Firebase.

## Cosa c'è nel kit

- `GUIDA-PER-CLAUDE.md`: i passi dell'installazione, scritti per Claude.
- `modello-repo/`: i file da mettere nel tuo repository GitHub (configurazione, regole del
  database, pubblicazione automatica, istruzioni per Claude).
- `esempi/`: un file di classi e un quiz di prova.

## Gli aggiornamenti

Non devi fare niente: ogni notte il tuo sito scarica da solo l'ultima versione di LiveLearn.
